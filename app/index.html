ENGINEERING CASE STUDY

From a private working system
to a focused public example.

This repository extracts the inspection layer of a larger local device-analysis project.

WHAT WAS BUILT

More than a prediction script.

The broader system combines data ingestion, device normalisation, text annotation, image-region annotation, model training, batch inference and manual review.

This public edition demonstrates the text and visual modelling approach, dataset hygiene, evidence handling and an interactive review workflow.

A DELIBERATE PUBLIC SCOPE

The inspection layer is portable.

Descriptions and images are treated as separate sources. Model suggestions remain distinct from confirmed facts. Missing evidence stays visible.

Commercial rules, source integrations, private listings, contacts and operational automation are outside this repository.

TECHNICAL CONTRIBUTION

Data contracts, training and the review loop.

Original work includes annotation semantics, partial-label handling, grouped splits, model orchestration, source-coordinate mapping and the review interface. ResNet18 and optional YOLO detectors are third-party architectures; OCR in the private system uses an external engine.
