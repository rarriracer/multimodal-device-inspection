# Third-party notices

This repository contains original portfolio code, synthetic text fixtures, original SVG artwork and a selected tensor export from an internally fine-tuned TorchVision ResNet18 view classifier. It does not bundle third-party Python packages.

The text baseline is trained from the included synthetic fixtures using scikit-learn. Runtime and training dependencies retain their respective upstream licences. No general open-source licence has been selected for the original project code at this stage.

## Optional Ultralytics adapter

The optional detector adapter imports the separately installed `ultralytics` package. No Ultralytics source distribution or detector checkpoint is bundled. This adapter is not used by the bundled ResNet18 model or the default illustrated walkthrough. Consult the upstream package and any supplied weights for their applicable terms.

## Visual assets

All six bundled device scenes are authored SVG illustrations generated by `scripts/create_examples.py`. They are not seller photographs. Screenshots are captured from this public demo; illustrated overlays must not be described as measured detector outputs.
